# 标签与说明书（Label & IFU）合规检查清单

> 用法：生成/审核标签与 IFU 后，逐项打勾。任一 P0 不通过 = 不可放行。
> 标注：🔴P0 强制硬项（缺失即不合规）｜🟡P1 条件项（视产品/市场）｜🔵 良好实践

---

## A. 识别与追溯要素

| 级别 | 检查项 | 中国 | 欧盟 | 美国 |
|------|--------|------|------|------|
| 🔴 | 产品名称、型号规格完整，覆盖全部交付配置 | ✔ | ✔ | ✔ |
| 🔴 | 制造商名称、注册地址 | ✔ | ✔ | ✔ |
| 🟡 | 欧盟授权代表（EC REP）名称地址 | — | ✔ | — |
| 🟡 | 进口商信息 | — | ✔ | — |
| 🔴 | UDI（中：UDI；欧：Basic UDI-DI+UDI-DI；美：UDI） | ✔ | ✔ | ✔ |
| 🔴 | 批号/序列号（LOT/SN） | ✔ | ✔ | ✔ |
| 🔴 | 生产日期与有效期（或等效） | ✔ | ✔ | ✔ |
| 🟡 | 注册证编号（中国）/ CE 标志及公告机构号（欧盟） | ✔ | ✔ | — |

## B. 预期用途与安全信息

| 级别 | 检查项 |
|------|--------|
| 🔴 | 预期用途/适应症清晰、明确，与注册资料一致 |
| 🔴 | 禁忌症完整（绝对/相对） |
| 🔴 | 警告（可致严重伤害）、注意（可致产品问题）分级清晰 |
| 🔴 | 残余风险与风险评估结论一致 |
| 🔴 | 目标使用者明确（医师/培训人员/患者） |
| 🟡 | MR 环境信息（MR Safe/Conditional/Unsafe + 条件） |
| 🟡 | 特殊材料声明（药物/动物源/人体源/纳米） |
| 🟡 | 患者人群限制（年龄/体重/孕哺等） |

## C. 无菌与一次性使用

| 级别 | 检查项 |
|------|--------|
| 🔴 | 无菌器械：标注无菌状态、灭菌方式、包装破损勿用 |
| 🔴 | 一次性器械："禁止重复使用" + 风险理由 |
| 🔴 | 标注"制造商灭菌的不得再灭菌"（如适用） |
| 🟡 | 复用器械：完整再处理程序（清洗/消毒/灭菌/包装/循环上限） |
| 🔴 | 灭菌方法已经确认并引用标准（ISO 17664/11135/11137/17665） |

## D. 使用、维护、储存与处置

| 级别 | 检查项 |
|------|--------|
| 🔴 | 操作步骤完整、按顺序、无歧义 |
| 🟡 | 手术技术（植入物）单独提供或在 IFU 引用 |
| 🟡 | 有源/软件：参数设置、报警、人机交互 |
| 🟡 | 维护校准周期、故障排查表 |
| 🔴 | 储存条件（温湿度/避光/压力） |
| 🟡 | 运输限制 |
| 🟡 | 废弃物处置（锐器/感染性/电池电子） |
| 🔴 | 制造商联系方式、不良事件报告渠道 |

## E. 符号与语言

| 级别 | 检查项 |
|------|--------|
| 🔴 | 符号使用 ISO 15223-1:2021，无自创易混淆符号 |
| 🔴 | "参阅说明书"符号正确 |
| 🔴 | 语言符合目标市场要求（欧盟=各成员国官方语言） |
| 🔴 | 多语言版本内容一致、无歧义 |
| 🟡 | eIFU 在线版本地址、有效期与获取方式 |
| 🔵 | 信息要素符合 ISO 20417:2026（注意：2021 版已 Withdrawn） |

## F. 用语与营销合规（中国重点）

| 级别 | 检查项 |
|------|--------|
| 🔴 | 无"疗效最佳""保证治愈""根治""无副作用"等断言性用语（中国局令第6号） |
| 🔴 | 无虚假、夸大、误导性表述 |
| 🔴 | 不暗示监管机构背书 |
| 🔵 | 术语规范、前后一致，与注册资料用语统一 |

## G. 版权与去敏（开源发布前专项）

| 级别 | 检查项 |
|------|--------|
| 🔴 | 开源仓库内无厂商原始 PDF / 受保护商标 / Logo / 专利图 |
| 🔴 | 无大段厂商 IFU 原文 |
| 🔴 | 禁词表（厂商名+产品名）CI 扫描零残留（产品文档/模板/示例） |
| 🔴 | 示例均为虚构产品，型号/数据/企业名为占位 |
| 🔴 | 模板要素依据标注到法规/标准，而非某厂商 |
| 🔴 | 含统一免责声明 |

---

## 判定规则

- **任一 🔴 P0 不通过 → 不可放行**，必须整改
- 🟡 P1 缺失 → 核查产品/市场是否适用，不适用需注明理由
- 🔵 良好实践缺失 → 建议优化

> 注：本清单为通用框架，具体产品还需结合产品类别专用标准（如植入物 ISO 14708、电气安全 IEC 60601 系列等）增补。
