# 厂商资料去敏规范与版权红线（强制）

> 本文件是 medxpert-labeling-ifu-skill 的**最高优先级合规约束**。
> 凡是涉及厂商真实产品资料（IFU、说明书、标签、手术技术、产品手册、临床资料）的使用，必须先过本规范。

---

## 一、版权红线（绝对不能碰）

本机有数千份厂商真实资料（DePuy Synthes 强生、Zimmer Biomet 捷迈邦美、Medtronic 美敦力、Stryker 史赛克、CONMED 等），它们的版权归各厂商所有。

### 🔴 禁止事项（任何一项都不能进开源仓库）

1. **禁止把厂商原始 PDF 放进任何开源 / MIT 发布的仓库**（无论是否收费）
2. **禁止大段照抄厂商 IFU 原文**（即使标注出处也不行）
3. **禁止使用厂商受保护的商标、Logo、产品名、专利图示**
   - 受保护产品名示例：ATTUNE、NexGen、Vanguard、Persona、ROSA、Oxford、TRUMATCH、LigaSure、Harmonic、Valleylab 等
4. **禁止复制厂商的设计图纸、手术示意图、产品照片**
5. **禁止把厂商临床数据原文（含具体数字、随访曲线）直接搬入开源材料**
6. **禁止暗示与某厂商有官方合作、背书或授权关系**（除非确有书面授权）

### 🟢 允许事项（可以进开源仓库）

1. **法规与标准的强制要求**：21 CFR 801、EU MDR Annex I §23、MDCG 2019-15、ISO 15223-1、ISO 20417、中国局令第6号——这些是公有领域的监管要求
2. **行业通用的 IFU 结构 / 章节框架**：章节标题、要素分类属于通用方法，不受版权保护
3. **基于多家厂商资料归纳的"共性规律"**：看完几十家后总结的通用模板（不是某一家的原文）
4. **完全虚构的、去品牌化的示例**：用"某厂家"、"示例膝关节假体系统"等
5. **标准符号**：ISO 15223-1 规定的符号本身（标准引用其编号，不复制厂商图）
6. **公开法规事实**：某产品的分类、注册路径、公开召回编号（openFDA 等公有领域数据）

## 二、去敏方法论（五步法）

把一份真实厂商 IFU 转化为可开源的通用知识，必须经过五步：

### 第 1 步：只提取"结构"，不提取"原文"

| 提取 | 不提取 |
|------|--------|
| 有哪些章节、章节顺序、覆盖了哪些要素 | 厂商的具体措辞、句式、段落 |
| 必备要素清单（适应症、禁忌、警告……） | 厂商的具体适应症描述文字 |
| 信息的组织逻辑 | 厂商的排版、配图、设计 |

### 第 2 步：跨多家归纳，单家不立证

- 任何"模板要素"至少要在 **3 家以上不同厂商**的 IFU 中出现，才可作为"行业通用结构"
- 只在某一家出现的内容，视为该厂商专有做法，**不写进通用模板**
- 本机 3,000+ 份资料足以支撑跨厂商归纳

### 第 3 步：彻底去品牌化

替换规则：
- `DePuy Synthes / Zimmer Biomet / Medtronic / Stryker` → `某制造商` / `示例厂家`
- `ATTUNE / NexGen / Vanguard` 等产品名 → `示例膝关节假体系统` / `[产品型号]`
- 具体型号、货号、订单号 → `[型号]` / `[REF]`
- 厂商客服电话、地址、网址 → 全部删除
- 具体临床数字（如"5年生存率98.7%"）→ 不引用，或标注为"需企业自有数据，此处仅占位"

### 第 4 步：源头改为"法规/标准"，而非"某厂商"

- 模板里每一个要素，要标注的依据是**法规标准**（如"依据 MDR Annex I §23.4(r)"），**不是**"某厂商就是这么写的"
- 这样即使结构与某厂商相似，也属于"对法规要求的独立实现"，不构成侵权

### 第 5 步：虚构示例占位 + 人工复核

- 所有示例使用明显虚构的产品（如"示例牌全膝关节假体系统，型号 DEMO-K1"）
- 发布前由人工做一次"品牌扫描"：grep 全部受保护商标词，确保零残留
- 建议维护一份《禁词表》（厂商名+产品名），CI 自动检查

## 三、真实资料的正确定位

```
真实厂商 PDF（数千份）
   ├── 位置：本地内部知识库（D:\Workbuddy\Claw\MedTech_Manuals 等）
   ├── 用途：内部学习、归纳共性、做对比研究、给付费客户做参考
   ├── 版权：归各厂商所有
   └── ❌ 绝不上传开源仓库、不公开分发、不进训练集对外暴露
           │
           │  （五步法去敏）
           ▼
去敏通用模板 / 检查清单（方法+法规要素）
   ├── 内容：行业通用结构、法规强制要素、去品牌化虚构示例
   ├── 版权：MedXpert 原创，可 MIT 开源
   └── ✅ 进开源仓库
```

**一句话总结**：
> 真实厂商文档是"内部教材"，我们只把"学成后的方法论和对法规的理解"开源，绝不把"教材原文"开源。
