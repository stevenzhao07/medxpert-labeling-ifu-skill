# 医疗器械说明书（IFU）通用标准模板 · 去敏版

> 本模板依据公开法规与标准编制：**EU MDR 2017/745 Annex I 第23条**、**MDCG 2019-15**、**ISO 20417:2026**、**ISO 15223-1:2021（符号）**、**美国 21 CFR Part 801**、**中国《医疗器械说明书和标签管理规定》（原局令第6号）**。
>
> 所有示例产品、型号、企业名、数据均为**虚构**，仅用于演示。不含任何厂商专有文档。

---

## 一、IFU 是什么 / 不是什么

- **标签（Label）**：贴在产品/包装上，解决"即时识别"——是什么、谁造的、批次、有效期、无菌状态、UDI。
- **说明书（IFU, Instructions for Use）**：随附文档，解决"正确安全使用"——预期用途、禁忌、警告、操作步骤、再处理、储存、处置。

二者要素有重叠，但**侧重点不同**：标签要素从简、符号化；IFU 要素从全、文字化。

---

## 二、IFU 必备要素清单（按 MDR Annex I §23.4 主干 + 中美增补）

> 标注【强制】的为法规明确要求；标注【条件】的为满足特定情形才需要。

### 0. 封面与识别信息
- 【强制】产品名称或商品名、**型号/规格**（覆盖全部交付配置）
- 【强制】制造商名称、注册商号/商标、注册地址
- 【条件】欧盟授权代表（EC REP）名称地址（进口到欧盟时）
- 【条件】进口商信息（如适用）
- 【强制】UDI-DI（基本 UDI），以及载体说明
- 【强制】说明书版本号 / 修订日期（Rev. 日期）
- 【强制】"请在使用前阅读说明书"符号（ISO 15223-1 符号 5.4.3 / 5.4.4）

### 1. 预期用途 / 适应症（Intended Purpose / Indications）
- 【强制】预期用途：产品用来做什么、作用机理概述
- 【强制】适应症：适用于哪些疾病/状况、解剖部位、患者人群
- 【条件】适用患者人群（年龄、性别、体重、适应症限制）
- 【条件】禁忌症：绝对禁忌、相对禁忌
- 【条件】目标使用者（仅医师 / 经培训人员 / 患者自用）

### 2. 安全信息（警告、注意、禁忌）
- 【强制】**警告（Warnings）**：可能导致死亡或严重伤害的风险
- 【强制】**注意（Precautions/Cautions）**：可能导致产品损坏或轻微伤害的风险
- 【强制】**残余风险**：风险评估后需告知使用者的风险
- 【条件】MR 环境信息（MR Safe / MR Conditional / MR Unsafe + 条件参数）
- 【条件】含药物/动物源/人体源/纳米材料成分的特别声明
- 【条件】一次性使用器械的"禁止重复使用"声明 + 理由
- 【条件】无菌器械的"无菌状态、包装破损勿用、禁止再灭菌"声明

### 3. 产品描述与组成
- 【强制】产品组成、各部件名称、规格型号表
- 【条件】配套器械/工具清单（哪些可与本系统配合使用）
- 【条件】材料（植入物的材料牌号/标准、涂层、药物成分）
- 【条件】工作原理 / 作用机理

### 4. 使用前准备
- 【强制】包装内容物清点
- 【条件】无菌包装检查（破损、潮湿、过期如何处理）
- 【条件】术前选型、影像/测量要求
- 【条件】电池/电源/软件版本检查（有源器械）

### 5. 操作步骤（使用说明）
- 【强制】按顺序的使用步骤
- 【条件】手术技术（植入物类，通常以独立 Surgical Technique 文档提供）
- 【条件】参数设置、报警阈值、人机交互（有源/软件）
- 【条件】一次性 vs 可重复使用的处理路径

### 6. 再处理（复用器械 / 清洁消毒灭菌）
- 【条件】复用器械的：使用点处理 → 清洗（手动+自动）→ 消毒 → 干燥 → 检查保养 → 包装 → 灭菌（方法、参数、循环次数上限）→ 储存
- 【强制】灭菌方法须经**确认（validated）**，引用 ISO 17664（复用器械再处理信息）、ISO 11135（EO）、ISO 11137（辐照）、ISO 17665（湿热）
- 【条件】器械最长使用寿命/最大复用次数及判定标准

### 7. 维护、保养、故障
- 【条件】定期维护项目与周期、校准
- 【条件】故障排查表（现象 → 原因 → 处理）
- 【条件】配件、备件、耗材的订购信息

### 8. 储存、运输、处置
- 【强制】储存条件（温度、湿度、避光、压力限制）
- 【强制】有效期 / 生产日期（符号化）
- 【条件】运输限制
- 【条件】废弃物处置（锐器、感染性废物、含电池/电子件）

### 9. 其他法规要素
- 【强制】制造商联系方式 / 不良事件报告渠道
- 【条件】CE 标志（欧盟合规）、公告机构编号（如涉及）
- 【强制】"不构成……"等必要免责声明
- 【条件】多语言版本一致性声明（MDR：各成员国官方语言）
- 【条件】说明书在线版本（eIFU）访问地址与有效期说明

## 三、去敏示例（虚构产品演示）

> 以下为**完全虚构**示例，展示一份骨科植入物 IFU 的要素如何填写，不含任何真实厂商信息。

### 示例：示例牌全膝关节假体系统（虚构型号 DEMO-TKA-01）

**产品名称**：示例牌全膝关节假体系统（DEMO-TKA 系列）
**制造商**：[虚构] 示例医疗科技有限公司（地址：[城市] [街道]）
**UDI-DI**：[占位] 0000000000000
**版本**：Rev. A，2026-01
**符号**：📖 请在使用前阅读说明书（ISO 15223-1 5.4.3）

**预期用途**：
DEMO-TKA 全膝关节假体系统用于因骨关节炎、类风湿性关节炎或创伤性关节炎导致膝关节严重破坏、需行全膝关节置换的成年患者，以重建关节功能、缓解疼痛。

**禁忌症（示例）**：
- 活动性或疑似感染、败血症
- 骨骼发育未成熟
- 严重骨质疏松或骨量不足以支撑固定
- 对产品材料（如 CoCrMo、Ti6Al4V、UHMWPE）过敏者

**警告（示例）**：
- ⚠️ 本产品为一次性使用无菌植入物，**禁止重复使用、再灭菌或重新包装**。重复使用可能导致感染、材料疲劳断裂。
- ⚠️ 包装破损、潮湿或超过有效期禁止使用。
- ⚠️ 术前应根据影像测量选择合适型号；型号不匹配可导致松动、脱位或早期失效。

**材料（示例）**：
- 股骨髁：钴铬钼合金（CoCrMo，符合 ISO 5832-12）
- 胫骨托：钛合金（Ti6Al4V，符合 ISO 5832-3）
- 衬垫：超高分子量聚乙烯（UHMWPE，符合 ISO 5834）

**储存**：常温干燥、避光、无腐蚀性气体环境储存。

**不良事件报告**：如发生严重不良事件，请联系制造商（[占位电话]）并向所在地医疗器械监管部门报告。

## 四、标签（Label）最小要素速查

标签（包装/产品上）通常只放"即时识别"要素，其余指向 IFU：

| 要素 | 中国 | 欧盟 | 美国 |
|------|------|------|------|
| 产品名称/型号 | 必须 | 必须 | 必须 |
| 制造商名称地址 | 必须 | 必须 | 必须 |
| 注册号/UDI | 必须（UDI） | Basic UDI-DI + UDI-DI | UDI |
| 生产日期/有效期 | 必须 | 必须 | 必须 |
| 批号/序列号 | 必须 | 必须 | 必须 |
| 无菌状态 | 条件 | 条件 | 条件 |
| 一次性使用 | 条件 | 条件 | 条件 |
| 储存条件 | 必须 | 必须 | 必须 |
| CE 标志 | — | 必须 | — |
| 授权代表 | — | 进口时 | — |
| 说明书符号 | 必须 | 必须 | 必须 |

> 符号统一引用 **ISO 15223-1:2021**，不得自创易混淆符号。

## 五、常见高频问题（去敏建议）

1. **真实厂商 IFU 能不能"改个名字"就用？**
   不能。改名不等于去敏，章节措辞、独特排版仍可能构成侵权。必须用本规范"五步法"，回到法规要素重新独立撰写。
2. **能不能引用厂商的临床数据？**
   开源模板中不放任何厂商专有临床数字；企业自有产品的数据由企业自行填写，模板只留占位。
3. **召回/不良事件里出现厂商名怎么办？**
   那是 openFDA 等公有领域的**事实陈述**（"某公司某编号召回"），可以引用，但要标明数据来源，不做评价。
4. **手术技术文档（ST）和 IFU 是一回事吗？**
   不是。IFU 是法定随附文件，ST 是操作指导。植入物厂商常以独立 ST 承载详细手术步骤，IFU 中引用。
